# ZeroCC Development Plan

## Project Overview

ZeroCC is a multi-ISA C99/C11/C23 compiler targeting x86-64, AArch64, and RISC-V with both an in-memory `W^X` JIT (`--run`) and AOT assembly/ELF backends (`-S`, `-c`, `-o`).

- **Full Changelog**: [`docs/CHANGELOG.md`](./CHANGELOG.md)

  - **`#warning` directive (C23 6.9.1, Sprint 132)**: preprocessor directive now emits `file:line: warning: #warning "text"` (the directive's own raw text as the message; empty argument legal; spliced lines merged; included files report their own name); inactive conditional groups stay silent; `#pragma GCC diagnostic ignored "-Wcpp"` suppresses / `warning "-Wcpp"` re-enables; `... error "-Werror"` escalates to a hard build failure (recorded via the preprocessor's failure channel, single-print like missing-include). Now: when the baseline rc is non-zero *and* the gcc reference builds the same source, an explicit zerocc compile probe runs and a failure is a sweep FAIL.   - **Strided & AoS Vectorization (Sprint 211)**: Support non-unit constant induction strides (`a[2*i]`) and Array-of-Structures layouts (`points[i].x`) via hardware strided memory ops (`OP_V128_LOAD_STRIDED`, `OP_V128_STORE_STRIDED`, RVV `vlse`/`vsse`, AArch64 structured lanes, x86 lane extraction).
  - **SLP (Superword-Level Parallelism) Vectorization (Sprint 212)**: Straight-line basic-block vectorization grouping isomorphic contiguous stores, memory copies, arithmetic, and scalar broadcasts without requiring loops (`opt_slp.c`).
  - **SIMD Remainder & Epilogue Vectorization (Sprint 217)**: Auto-vectorizes loops with non-multiple trip counts across integer and float operations and horizontal reductions.
- **Advanced Loop Optimizations (Sprints 215–216)**:
  - **Loop Unswitching (Sprint 216)**: Hoists loop-invariant conditional branches (`if (flag)`, `if (mode == 1)`) outside loop bodies by cloning the loop into specialized branches (`opt_loop_unswitch.c`), eliminating per-iteration branch evaluation overhead and exposing straight-line loop bodies.
  - **Loop Peeling (Sprint 216)**: Peels the initial iteration of countable loops into the preheader, resolving first-iteration boundary checks (e.g. `if (i == 0)`) into compile-time constants and eliminating boundary branches.
  - **LICM Store Hoisting / Scalar Replacement of Aggregates (SROA, Sprint 215)**: Hoists invariant memory writes (`*p = val`, `p->field += val`) outside loop bodies by loading into a register accumulator in the preheader and committing the final store on loop exit (`opt_licm_store_hoist`).
  - **Loop Fusion / Jamming (Sprint 215)**: Merges adjacent loops with identical trip counts, matching bounds, and compatible data dependencies into a single combined loop body (`opt_loop_fusion.c`), eliminating redundant loop index increments and branch overhead while exposing larger instruction windows to GVN, SLP, and SIMD auto-vectorization.
- **Direct ELF Section Emission & Extended Linker Dead-Stripping (`--gc-sections`, Sprint 213)**:

## 🚀 Multi-ISA Target Architecture Refactoring Plan

**Goal**: Transition ZeroCC from coupled `if (c->isa == ...)` checks (over 80+ locations) and the monolithic 150+ slot `ZeroCCISABackend` into a clean, declarative target-trait and modular plugin model for hosted and baremetal CPUs (x86-64, AArch64, RV64, RV32, AArch32, MIPS), while keeping GPU (PTX / SPIR-V) as a separate standalone project in its own repository (`zero_gpu`).

### Phase Breakdown:
1. **Phase 1 (TargetTraits)**: Declarative `TargetTraits` queryable from the backend (`ptr_size`, `word_size`, `stack_align`, `has_red_zone`, `ret_gpr_lo/hi`, `sret_gpr`, `sret_consumes_arg0`, `elf_machine`, `elf_flags`, `dwarf_addr_reloc`). Eliminates ~50 ad-hoc ternary checks across AST lowering, `main.c`, `dwarf.c`, and `elf_writer.c`.
2. **Phase 2 (Table-Driven Regalloc)**: Declarative `TargetRegDesc` bitmasks for allocatable, callee-saved, and reserved GPRs, scratch registers, and vector counts. Decouples `regalloc.h` into an ISA-agnostic linear-scan engine.
3. **Phase 3 (Decoupled ABI & Call Lowering)**: Target ABI classification interface (`classify_arg`, `classify_return`) replacing struct eightbyte and register/stack routing in `ast_lowering_call.c` and `ast_lowering_varargs.c`.
4. **Phase 4 (Modular Linker Relocations)**: `TargetLinkerOps` (`apply_reloc`, `write_plt`) extracted from `src/zero_cc/linker/linker.c` into target-specific relocation tables (`src/zero_cc/linker/arch_*.c`).
5. **Phase 5 (Clean ASM Emitter Separation)**: Table-driven instruction formatting or complete hook coverage in `src/zero_cc/ir/asm_emitter.c`, eliminating direct `fprintf` instruction strings with hardcoded ISA checks.
6. **Baremetal CPU Extensions**: Linker script LMA/VMA support (`-T script.ld`), baremetal `crt0`, and `OS_BAREMETAL` trait to bypass POSIX/Linux syscall wrappers in `zero_rt`.
7. **Cross-TU Dead Code & Data Elimination (`--gc-sections`, Sprint 190)**: Mark-and-sweep section garbage collection across object files and archives, eliminating unreferenced functions and data variables. Paired with `-ffunction-sections`, `-fdata-sections`, and linker script `KEEP(*(pattern))` directives to preserve reset vectors and hardware tables.
8. **Standalone GPU Compiler Repository (`zero_gpu`)**: Maintained as an independent project in its own dedicated repository, specialized for SSA IR, divergence analysis, multiple address spaces, and bytecode/text emission (PTX/SPIR-V), driven by ZeroCC host binaries via standard dynamic GPU runtime libraries.

### Tier 1: Local & Low-Complexity Passes (Status: 100% Complete ✅)
1. **Constant Folding (Complete ✅)**: Compile-time constant binary/unary evaluation across integer, floating-point, `__int128`, and complex types (`opt_constant_fold.c`).

3. **Strength Reduction (Scalar) (Complete ✅)**: Powers-of-2 mul/div/mod lowered to shifts and masks across all 5 ISA emitters.
4. **Local CSE (Complete ✅)**: Basic-block hash-based subexpression elimination (`opt_cse.c`).
5. **Dead Code Elimination (DCE) (Complete ✅)**: Backward liveness analysis removing unreferenced pure instructions (`opt_dce.c`).
6. **Branch Simplification & Unreachable Block Removal (Complete ✅)**: CFG dead block pruning and constant branch folding (`cfg.c`, `opt_branchless.c`).

### Tier 2: SSA & Global Dataflow Passes (Status: 100% Complete ✅)
7. **Mem2Reg (Complete ✅, Sprints 220, 239)**: Stack slot forwarding, cross-block loop-carried induction/accumulator promotion (`opt_mem2reg.c`), and If-Then-Else diamond-merging virtual register promotion across join blocks (`opt_mem2reg_join.c`).
8. **Sparse Conditional Constant Propagation (SCCP) (Complete ✅, Sprint 237)**: Simultaneous constant propagation across CFG edges, conditional branch folding, and unreachable block pruning (`opt_sccp.c`).

10. **Aggressive Dead Code Elimination (ADCE) (Complete ✅, Sprint 230)**: Classical reverse-mark worklist from program roots (stores, calls, returns), pruning dead loops and unused induction variables without trip-count evaluation (`opt_adce.c`).
11. **Tail Call Optimization (TCO) (Complete ✅, Sprint 229)**: Reusing caller stack frames via direct jumps (`jmp`) for self-tail-recursive calls and eligible sibling calls (`opt_tco.c`).
