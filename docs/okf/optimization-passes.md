# Optimization Passes & Safety Invariants

Optimization passes are registered in `src/zero_cc/opt/opt_pass.c` (`g_opt_passes`) and execute sequentially over `ZeroCCCompiler`'s `IRArena`.

## Active Optimization Pipeline

1. **Constant Folding (`opt_constant_fold.c`)**
   - Evaluates constant binary/unary operations at compile time and replaces instructions with `OP_MOV_IMM`.
2. **Copy Propagation (`opt_copy_prop.c`)**
   - Propagates `OP_MOV_REG` and constant definitions across basic blocks, invalidating mappings at labels and redefinitions.
   - **Generic definition rule (Sprint 39)**: `instr_defines_temp` treats **any instruction with `temp_dest != TEMP_NONE`** as a definition (matching DCE's liveness convention), with `OP_CALL`/`OP_CALL_INDIRECT` excluded (their `temp_dest` is not a temp ID since C2b). The previous explicit opcode list missed the in-place ops (`OP_ADD_IMM`, `OP_SUB_INC`, `OP_INC`, `OP_DEC`, `OP_SEXT*`, `OP_ZEXT*`, `OP_LEA`, …), so an in-place redefine of a copy-mapped temp was not invalidated and later uses were replaced with the stale copy source (e.g. `t2 = t; t2 = t2 - 1; r = ~t2` miscompiled as `r = ~t`). Latent before Sprint 39 because lowering only ever emitted 3-operand forms for `x += c`; the branchless-select pass was the first emitter of in-place `SUB_INC` on a copied temp and exposed it.
3. **Common Subexpression Elimination (`opt_cse.c`)**
   - Eliminates redundant pure expressions within basic blocks while respecting flag-setting instructions (`REG_FLAGS`).
4. **Global Value Numbering (`opt_gvn.c`)**
   - Block-scoped hash-based value numbering: duplicate numberable expressions (`ADD/SUB/MUL/AND/OR/XOR/SHL/SHR/NEG/NOT/MOV_REG/MOV_IMM`) in a block are replaced with copies of the first occurrence; the value table resets at every `OP_LABEL`.
   - A second scan does **restrict-aware redundant-load elimination / store-to-load forwarding** (`opt_restrict_memory_forward`): loads are keyed on (width, canonical address temp); loads from the same unmodified stack slot share a canonical temp; untagged stores clobber all pending entries, `restrict`-grouped stores only their own group; a 64-bit store forwards its value to later 64-bit loads of the same address.
   - **O(1) block reset (Sprint 38)**: the canonical-temp table (`g_canon`, full 16-bit temp-id space) uses **generation stamps** — `mf_reset()` bumps a generation counter instead of rewriting all 65536 slots (the rewrite ran at *every* block boundary — 447× per large function — and measured ~60 ms per function of the ~65 ms GVN total; now ~2.3 ms total per function at `-O2/-O3` on `synth_large.c`).
5. **Small Function Inlining (`ast_lowering_expr.c` / `jit/compile.h`)**
   - Automatically inlines static and `inline` leaf/helper functions ($N \le 35$ AST nodes, non-variadic, no struct returns $>8$B, non-recursive) at `-O2`/`-O3` (up to depth 2).
   - Candidate function bodies are cloned from function-local AST arenas into TU-level `tu_ast_arena`.
   - At call sites, argument expressions are evaluated to temporaries, bound to parameter identifiers, and the inlined body is lowered directly into caller IR, routing returns to destination temporaries without call instruction or stack frame overhead.
   - Subsequent passes (`mem2reg`, `licm`, `copy_prop`, `dce`) optimize seamlessly across the inlined boundary.
   - **Sprint 35 Phase 1 audit — conservative candidate filters**: the call-site expander re-lowers the body in the CALLER's context, where the callee's parse-time state is unavailable or collides. `jit/compile.h` therefore rejects candidates whose signature or body has any of: **float/double param or return** (param substitution forces `last_expr_is_float=0`; FP params/returns misroute between GPR and XMM), **any local declaration in the body** (locals are registered at parse time in the callee's per-function table and reset per function, so body locals lower to `TEMP_NONE` at the call site), **any label/goto** (user labels resolve through a global name-based map, so a same-named caller label aliases the inlined target), or **`&param`** (value params bind to virtual registers with no address; `&param` lowers to an invalid LEA). The AST walkers `zero_cc_ast_has_local_decl`, `zero_cc_ast_has_label_goto`, and `zero_cc_ast_addr_of_param` (`parser/ast_arena.h`) implement these checks. Verified-safe-and-still-inlined: expression-only leaf helpers, struct params/returns ≤8B, multiple returns, real calls from the inlined body, nested depth 2, same callee twice in one expression. Audit battery: `test/inline_audit/` (17 differential tests, part of `make test-opt`). Re-enabling bodies with locals (snapshot name+type before the callee's local table is reset, re-register into the caller's frame with a name-collision check) and FP signatures (carry param types through the inlining context) are the planned follow-ups.
6. **Local & Cross-Block Mem2Reg (`opt_mem2reg.c`)**
   - Forwards stack stores (`OP_MOV_MEM`) to subsequent stack loads (`OP_MOV`) to eliminate redundant stack traffic.
   - **Straight-Line & Fallthrough Optimization**:
     - Preserves slot tracking across conditional branches (`OP_JE`, `OP_JNE`, `OP_JL`, `OP_JLE`, `OP_JG`, `OP_JCOND`) along the fallthrough path.
     - Detects unreferenced labels (such as `loop_step` in for-loops without `continue`) and skips slot invalidation.
     - Preserves slot mappings across in-place sign/zero extensions (`OP_SEXT32`/`OP_ZEXT32`).
     - Tracks loaded temps so subsequent loads from the same slot in the straight-line path reuse the loaded temp.
   - **Cross-Block Loop Promotion (`opt_promote_loop_carried`)**:
     - Detects natural loops with induction variables and accumulators that are not address-taken (`!slot_addr_taken`). **Loop structure comes from the CFG (Sprint 35 Phase 3)**: `cfg->loops[]` backedges, still restricted to unconditional `OP_JMP` backedges; the first exit is the earliest CFG successor of a loop block past the backedge (replaces the legacy function-wide jump-target pre-scan).
     - Converts preheader initialization stores (`MOV_MEM [S], T_init`) and backedge stores (`MOV_MEM [S], T_update`) into virtual register transfers (`OP_MOV_REG T_head, ...`), and replaces the in-loop load with `OP_NOP`.
     - **Conservative slot audit (Sprint 35 Phase 0)**: a slot is promoted only if the ENTIRE function is auditable - exactly one in-loop load and one in-loop store, exactly one out-of-loop store (the preheader init, strictly before the header), and every remaining load strictly after the loop exit. Other loads before the exit or any extra store disqualify the slot. ALL post-loop loads (until `RET`/`OP_EPILOGUE` or a store to the same slot) are forwarded to the head temp - forwarding only to the next label is insufficient because code after the loop (e.g. a post-loop print) still reads the stale slot.
     - **Loop entry-cleanness guard (Sprint 35 Phase 0; CFG-based since Phase 3)**: the loop is disqualified from promotion if any **explicit jump edge** from a block OUTSIDE the loop range (a non-adjacent target, or an unconditional `OP_JMP` into the next block) enters any loop block - fall-through from the preheader is not a jump and stays allowed. Such an entry skips the preheader init, leaving the promoted head temp uninitialised where the original in-loop load would have read the slot (see `test/jit/goto_into_loop.c`).
     - Completely eliminates stack memory reads and writes from the inner loop body for promotable loop-carried variables (dropping loop-simple to 0 stores in the loop).
   - **Critical Safety Invariants**:
     - Only tracks 8-byte aligned stack slots (`offset % 8 == 0`) whose stored source is a virtual register (`temp_src1 >= 16`). Reserved physical registers (`VREG_0`..`VREG_15`, `< 16`) are never forwarded across instructions by `opt_mem2reg.c`, `opt_copy_prop.c`, `opt_cse.c`, or `opt_gvn.c` because their live ranges are not tracked by the general register allocator.
     - When a sub-8-byte or unaligned store occurs (e.g., writing a 4-byte struct field at `-68(%rbp)` via `OP_LEA` + `OP_STORE_32`), **both** overlapping 8-byte boundary slots (`(-offset)/8` and `(-offset + 7)/8`) must be invalidated so stale 64-bit values are never forwarded to subsequent 8-byte struct loads.
     - Address-taken variables (`OP_LEA`), indirect writes (`OP_STORE_*`), and calls inside loops invalidate or disqualify loop promotion to maintain memory consistency.
7. **Loop-Invariant Code Motion (`opt_loop.c`)**
   - Identifies natural loops via **CFG backedges (Sprint 35 Phase 3)**: `detect_loops` iterates `cfg->loops[]` (header = `blocks[header].start`, body = `[blocks[header].start .. blocks[backedge_from].end)`); no private `label_to_idx` map remains. Note `detect_loops` may produce **multiple `LoopInfo` entries sharing one header** (several backedges into the same label, e.g. `continue` + main backedge).
   - Uses a **Two-Pass Rebuild** into a new `IRArena`: hoists pure loop-invariant instructions immediately before the loop header label, turns their in-loop originals into `OP_NOP`, and updates `c->ir_call_args` instruction indices.
   - **Shared-Header Emission (Sprint 35 Phase 0)**: when several loops share a header, the rebuild must emit the UNION of all those loops' invariants before the header (deduplicated via `emitted_at_header`). Emitting only the first matching loop's invariants loses definitions: the in-loop copies of the later loops' invariants are still NOP'd, leaving the temps undefined (Sprint 33 regression: `MOV_IMM r51, 1` in `break_continue.c` hoisted for loop A but the in-loop copy NOP'd under loop B's marking).
   - **Stack Load & Extension Invariant Hoisting**: Detects read-only stack slots (loaded but never stored to in the loop body, no pointer aliasing, no calls) and hoists `OP_MOV` and downstream `OP_SEXT`/`OP_ZEXT` instructions out of the loop into the preheader (e.g. loop bound `n`).
   - **Call-Spanning Safety Invariant**: Does not hoist loop-invariant constants/expressions out of loops that contain `OP_CALL` or `OP_CALL_INDIRECT`, preventing hoisted temporaries from exceeding the 5 callee-saved GPRs on x86-64 and spilling into caller-saved registers across calls.
   - **In-Loop Definition Invariant**: An instruction is hoisted only if every definition of each source operand either lies outside the loop body before the header, or (within the body) is itself marked invariant. A source defined ANYWHERE in the body - including AFTER the candidate, which feeds back through the backedge on the next iteration - makes the candidate loop-dependent. This is what protects promoted induction variables: after mem2reg + copy propagation the increment is `ADD r_new, i, 1` with `i` defined by the backedge write-back at the bottom of the loop; without this check the ADD would be hoisted and `i` frozen. In-place self-references (`SEXT32 r, r`) are exempt when they are the body's only definition of that temp.
8. **SIMD Auto-Vectorization (`opt_vectorize.c`)**
   - Detects countable array arithmetic loops:
     - **Single-Precision Floats (`float[N]`)**: maps `OP_VLOADSS`, `OP_VSTORESS`, `OP_FADD`/`OP_FSUB`/`OP_FMUL`/`OP_FDIV` &rarr; 128-bit packed single vector instructions (`OP_VADDPS`, `OP_VSUBPS`, `OP_VMULPS`, `OP_VDIVPS`, `OP_VLOAD`, `OP_VSTORE`) with `vec_width = 4` (stride 4, `i += 4`).
     - **Double-Precision Floats (`double[N]`)**: maps `OP_VLOADSD`, `OP_VSTORESD`, `OP_FADD`/`OP_FSUB`/`OP_FMUL`/`OP_FDIV` &rarr; 128-bit packed double vector instructions (`OP_VADDPD`, `OP_VSUBPD`, `OP_VMULPD`, `OP_VDIVPD`, `OP_VLOAD`, `OP_VSTORE`) with `vec_width = 2` (stride 8, `i += 2`).
     - **32-Bit Packed Integers (`int[N]`)**: maps `OP_LOAD_32`, `OP_STORE_32`, `OP_ADD`/`OP_SUB`/`OP_MUL` &rarr; 128-bit packed integer vector instructions (`OP_VPADDD`, `OP_VPSUBD`, `OP_VPMULLD`, `OP_VLOAD`, `OP_VSTORE`) with `vec_width = 4` (stride 4, `i += 4`).
     - Supports multi-ISA backend lowering across x86-64 SSE2/SSE4.1 (`paddd`, `psubd`, `pmulld`), AArch64 NEON (`add.4s`, `sub.4s`, `mul.4s`, `fadd.2d`, `fadd.4s`, `ldr/str q`), and RISC-V RVV 1.0 (`vsetivli zero, 4, e32, m1`, `vadd.vv`, `vsub.vv`, `vmul.vv`, `vfadd.vv`, `vle32.v`/`vse32.v`).
   - **Call-Safety Invariant (C11)**: a loop is only vectorized if its body contains **no `OP_CALL` / `OP_CALL_INDIRECT` / `OP_RET`** (`has_call` guard in `analyze_loop_for_vectorization_full`). The transform widens the induction step (`i += 1` → `i += vec_width`) and converts scalar loads/arith/stores to 128-bit lane ops - a call (or return) in the body cannot be replicated across lanes and would run only once per `vec_width` iterations, silently dropping loop iterations (pre-existing miscompile: `for(...) { float t = use2(1.0f); s += t; }` incremented `k` by 4).
   - **Mid-Body Conditional Hardening (Sprint 35 Phase 3, supersedes `5766bee`)**: a conditional jump is permitted only if it IS the backedge (block ending at `loop->exit_idx`) or it is the header block's loop test whose target lies outside the loop span; any other conditional in the span (an `if`/`else` in the body) rejects the loop. The legacy per-instruction span scan is gone - and with it its fatal over-rejection: the loop's own header test (a forward `JE`-to-exit inside the span) used to be flagged, so while-style loops were never vectorized and the pass was effectively dead. The increment rewrite only matches the loop counter (`loop_var_temp`), not any `OP_ADD` with constant 1.
   - **Loop-Bound Safety Prerequisite (Sprint 35 Phase 3)**: the transform widens the induction step (`i += 1` → `i += vec_width`) with **no remainder handling**, so a loop count not a multiple of `vec_width` makes the final `VLOAD`/`VSTORE` overflow the array into adjacent stack. A loop is accepted only if the loop-test chain (branch → `OP_COND_SET` → `OP_CMP` → constant operand) yields a **compile-time constant bound that is a positive multiple of `vec_width`**. Variable bounds, FP bounds, and infinite loops (no verifiable test) are not vectorized.
   - **Optimization levels**: default is `-O1`. `-O1`: constant_fold, flag_dce, dce, copy_prop, mem2reg. `-O2`: + cse, gvn, licm, small-function inlining. `-O3`: + strength_reduction, branch_simplify, auto_vectorize, branchless (Sprint 39). `-O0` runs no passes.
   - **Sprint 33 regression RESOLVED (Sprint 35 Phase 0, 2026-10-20)**: the `-O1`+ `break_continue`/`goto_loop` and `-O2`+ `loops_conditionals`/`test/licm/*` miscompiles stemmed from (a) `x86_emit_extend`/`x86_emit_extend_asm` emitting `MOVSXD`/`MOV` with the wrong source register in the ModR/M, (b) `x86_emit_cond_set_asm` hardcoding `%al` and clobbering live `RAX`, (c) the LICM shared-header invariant-loss bug above, (d) LICM hoisting loop-dependent `ADD`s (in-loop source check missing), and (e) DCE single-sweep liveness deleting backedge write-backs. Verified by `make test-opt` (88/88 at `-O0..-O3`, JIT + AOT).
9. **Dead Code Elimination (`opt_dce.c`)**
   - Marks unused temporaries and dead instructions as `OP_DEAD` / `OP_NOP` while preserving instructions with side effects (stores, calls, volatile loads, flag setters consumed by branches).
   - **Fixpoint Liveness (Sprint 35 Phase 0)**: liveness is computed by iterating the backward sweep over a MONOTONIC live set until it stops growing (bounded at 10 sweeps; on non-convergence DCE marks everything live and deletes nothing). A single backward sweep is unsound in the presence of loops: a temp defined at the bottom of the loop (a promoted induction variable's backedge write-back) and used at the top appears dead at its definition on the first sweep, so DCE would delete the update and turn the loop infinite. The pipeline's fixed-point iteration (`opt_run_passes`, up to 10 rounds) re-runs DCE after later passes create new loop-carried register values, which is why this bug only surfaced once CSE/GVN/LICM ran at `-O2`.
10. **Branchless Conditional Select (`opt_branchless.c`, Sprint 39)**
    - `-O3` only (priority 58: after LICM, before strength reduction). Converts ternary-lowering branch shapes into the branchless bitwise select `mask = (t ? -1 : 0); res = B ^ (mask & (A ^ B))` - exact for any 64-bit pattern (int, pointer, struct chunk), no new opcode needed.
    - **Matched shape**: `JE t, L_else` preceded by the condition definition, then arm `JMP L_end`, `L_else:`, else arm, `L_end:`. Each arm must be pure value plumbing - one of `MOV_REG res, A` / `[LOAD|copy] V + MOV_REG res, V` / `[LOAD|copy] V + SEXTn/ZEXTn V + MOV_REG res, V` - no calls, stores, or jumps. The copy form (`MOV_REG V, A`) appears after copy-prop replaces the arm's frame load with a copy of a live temp.
    - **Two condition forms**: (a) the preceding instruction is `OP_COND_SET` defining `t` (t is exactly 0/1; mask = `t * -1`); (b) the preceding instruction is flags-neutral and `t` is a provably GPR-resident arbitrary int (the register-form jump tests `t == 0`; mask = `((t == 0) ? 1 : 0) - 1` via `OP_CMP_ZERO` + `OP_COND_SET CC_EQ` - the same sequence lowering uses for `!x`).
    - **Mask opcodes are -S-safe by construction**: `asm_emitter.c` (the `-S` path) originally had no emitters for `OP_NOT`/`OP_INC`/`OP_DEC`/`OP_ADD_IMM`/`OP_SUB_IMM`/`OP_LNOT` (it emitted a `# UNKNOWN` comment - since **Sprint 40** all six have emitters on every backend). The mask/select therefore use only `OP_MOV_IMM`, `OP_MUL`, `OP_SUB`, `OP_XOR`, `OP_AND`, `OP_CMP_ZERO`, `OP_COND_SET`, all supported by both code paths.
    - **Safety invariants** (all enforced in `try_match_site`): CFG predecessor checks via the shared CFG layer - `L_else`'s block has exactly the JE-block as predecessor, `L_end`'s block exactly `{then-block, else-block}`; `res` is not read anywhere in the replaced span; `res`/arm values `!= t`; both arm values provably GPR-resident (definition walk over GPR-producing opcodes; float/double locals load via `OP_FLOAD` into XMM class and are rejected, as is any frame slot whose local type is `float`/`double`); the condition temp stays live (it feeds the mask); 4 fresh temps per site with a 16-bit temp guard. The two-pass arena rebuild (LICM recipe) splices the hoisted arm plumbing + mask + select and remaps `ir_call_args`.
    - **Flags are safe to clobber at the merge point**: every jump in the IR is register-form (`JE t` = `test t, t; je`), and the only flag-reading opcode is `OP_COND_SET`, which lowering always places adjacent to its `OP_CMP`/`OP_CMP_ZERO` - no lowered flag reader can straddle the splice.
    - Verified by `test/jit/ternary_branchless.c` (part of `make test-opt`, all `-O` levels, JIT + AOT) and a gcc differential battery (plain/comparison conditions, negative/large values, pointer arms, SEXT arms, condition reuse, nested ternaries, loop-carried selects).
    - **Known non-matches (by design)**: ternaries whose arms are FP values (XMM guard), whose arms compute (e.g. `? -x :`), whose arms are bare immediates, and `char`/`short` *pointer* arms are fine but struct-by-value arms are out of scope (v2 candidates: immediate arms, struct chunks).

## Known Issues Surfaced During Sprint 39 (ALL RESOLVED in Sprint 40)

- ~~**Float/double ternary miscompiles at -O0**~~ - **FIXED (Sprint 40)**: FP ternaries now define the result temp with `OP_FMOV` (XMM class) and convert mixed int/FP arms per the C usual arithmetic conversion; see `docs/CHANGELOG.md` [Sprint 40].
- ~~**64-bit literals > 32 bits in ternary arms / XOR operands miscompile at -O0**~~ - **FIXED (Sprint 40)**: root cause was the lexer misclassifying hex literals containing an `E`/`e` digit as hex floats (C99 6.4.4.2: a hex literal is a float only with `.` or `p`/`P`); `0x123456789ABCDEFLL` now lexes as a long long.
- ~~**`-S` asm_emitter opcode gaps**~~ - **FIXED (Sprint 40)**: `OP_ADD_IMM`, `OP_SUB_IMM`, `OP_INC`, `OP_DEC`, `OP_NOT`, `OP_LNOT` all have `-S` emitters on all three backends (the earlier list naming `OP_SUB_INC`/`OP_ADD_INC` was a misnomer - those opcodes do not exist). The Sprint 39 branchless pass's `-S`-safe mask restriction remains valid but is no longer load-bearing.
